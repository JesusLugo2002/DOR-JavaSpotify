# JavaSpotify

A simple audio player online with three songs, stylized like vinyl records with photos from their albums. The songs are:

- BIG SHOT, by Toby Fox.
- Ludwig, the Holy Blade, by Nobuyoshi Suzuki.
- World's End Valentine, by OMORI.

This was created as homework for the Web Design subject of my Web Application Development formation.

## Technologies

- `HTML`
- `CSS`
- `JavaScript`
- `npm`
- `parcel-bundler`

## What I learned

### Identifiers for CSS

I learned how to assign classes and identifiers to HTML elements to apply the corresponding style determinated and how CSS selectors works.

### JavaScript fundaments

I created my very first JavaScript classes to manage the audio player, assign an _OnClick_ callback to play the songs and the animation at the same time programatically.

### CSS Flex and Transition properties

I learned how to use the flex property to positionize the elements in the screen to stylize and setup the transition property to play the vinyl animation.

### How use `npm` and deploy in Github Pages

I deployed my very first web app using `npm` to install `gh-pages` package, allowing me to deploy this little project in Github Pages and make it available to everyone without downloading any line of code.

### How `parcel-bundler` works

I used the `parcel-bundler` package to run a development server that helps me with the app creation and also compress the project assets into bundles to deploy it more lightweight and fast.
